# Bulgarian JetBrains IDE Localization

Този проект има за цел да предостави пълна българска локализация на средите за разработка предоставени от JetBrains, в това число:
* IntelliJ IDEA
* CLion
* PyCharm
* WebStorm
* други

Текущата версия е автоматичен превод от плъгина предоставящ превод на Руски език. В следствие на което има много неточности, които следва да бъдат изчистени в бъдещи версии.

## Как да използвате локализацията
* Клонирайте проекта на вашия компютър.
* Направете ZIP архив от папките [META-INF](./META-INF) и [messages](./messages).
* Преименовайте архива до ``без_значение.jar``
* Отворете средата за разработка на JetBrains.
* Отидете на `File` -> `Settings` -> `Plugins`.
* Натиснете на иконката с зъбно колело горе вдясно и изберете `Install Plugin from Disk...`.
* Изберете създадения файл ``без_значение.jar`` и натиснете `OK`.
* Рестартирайте средата за разработка.
